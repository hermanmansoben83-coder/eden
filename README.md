WEBSITE GKI EDEN MANSOBEN — PAKET SIAP UPLOAD
================================================

File utama:
- index.html

CARA UPLOAD:
1. Buka layanan hosting yang mendukung static HTML.
2. Upload file index.html atau upload ZIP ini setelah diekstrak.
3. Pastikan index.html berada di folder utama (public root).
4. Hosting akan memberikan alamat HTTPS publik.

CATATAN PENTING:
- Alamat seperti https://www.eden.html bukan format domain yang benar.
- Contoh alamat sementara yang benar: https://nama-proyek.netlify.app
- Jika ingin alamat sendiri, gunakan domain seperti:
- gunakan domain https://gkiedenmansoben.org

RESPONSIVE:
Website sudah menggunakan viewport dan layout responsif sehingga dapat dibuka
di komputer, laptop, tablet, dan HP.

CATATAN SISTEM:
Website saat ini memakai React melalui CDN dan sebagian data admin masih
tersimpan di state browser. Untuk penggunaan gereja secara nyata oleh banyak
admin/perangkat, tahap berikutnya sebaiknya dihubungkan ke database online
dan autentikasi server.

Jangan memasukkan file rahasia/password database ke website publik.
